Overview

Borrowed, reusable view over one sample's numeric FORMAT values. The view is valid only until the accessor advances to the next sample or fetches the same FORMAT field again. Call #to_a to retain its values.

def each
  return to_enum(__method__) unless block_given?

  @length.times do |index|
    ensure_valid!
    byte_offset = (@offset + index) * 4
    word = @pointer.get_uint32(byte_offset)
    break if vector_end?(word)

    yield decode(word, byte_offset)
  end
  self
end
